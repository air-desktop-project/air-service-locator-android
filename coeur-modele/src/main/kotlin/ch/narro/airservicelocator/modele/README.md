# coeur-modele

Les types que l'application manipule : utilisateur, machine, service, bail.

**Vide.** Le modèle est spécifié dans le dépôt serveur, `docs/modele.md` — et il
n'y est pour l'instant qu'une liste de questions. Le recopier ici avant qu'il
soit arrêté ferait deux versions dont l'une vieillirait en silence.

Ce module ne dépend de RIEN — ni d'Android, ni du réseau. Tout ce qu'on y écrit
doit rester éprouvable sur la JVM, sans émulateur.
